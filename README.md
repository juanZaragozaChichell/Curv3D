# Print3D

*Print3D* (read as 'printed') is a Python library for non-planar 3-axis 3D printing using FFF. Further descriptions will come.


# Installation

Tested with python 3.12

Full control libray:
    pip install git+https://github.com/FullControlXYZ/fullcontrol

# Usage

## GCode generation
Generate GCode from a list of points. An example is shown in gcode_generation.py file.
The GCode can be then viewed in PrusaGCode viewer for example.
